Sou apaixonado por construir sistemas escaláveis, resilientes e bem estruturados. Atualmente, dedico meus estudos à compreensão profunda dos fundamentos da computação, boas práticas de código (**Clean Code** e **TDD**), arquitetura de microsserviços e ecossistemas em nuvem.

* 🎯 **Objetivo:** Aplicar rigor técnico e boas práticas de engenharia para resolver problemas reais e construir soluções backend de alta performance.
